# ميدان المعرفة — Midan Al-Maarifa

مسابقة جماعية تفاعلية باللغة العربية: يتنافس المشاركون في اللحظة نفسها من أجهزتهم دون الحاجة إلى أي حساب.

**العب الآن:** https://osamaalruqaishi-tech.github.io/midan-almaarifa/

## طريقة اللعب
- **المشرف** يفتح الرابط ويضغط «إنشاء لعبة» فيحصل على رمز من 6 أرقام ورابط دعوة ورمز QR.
- **المتسابقون** يفتحون الرابط أو يمسحون الرمز، ثم يكتبون أسماءهم ويصممون شخصياتهم.
- يبدأ الجميع معاً، ويستطيع المشرف إيقاف اللعب مؤقتاً واستئنافه.

## المحتوى
- 7 أنواع أسئلة: اختيار من متعدد، الأقرب للصواب، صح وخطأ، الأسرع، اذكر أكبر عدد، اكتب الإجابة، رتّب.
- 11 موضوعاً: التاريخ الإسلامي، السيرة النبوية، القرآن الكريم، الرياضيات، العلوم، الجغرافيا، التاريخ العماني، ألغاز، دول وعواصم، نحو، معلومات عامة.
- التقييم: 80% للإجابة الصحيحة و20% للسرعة.
